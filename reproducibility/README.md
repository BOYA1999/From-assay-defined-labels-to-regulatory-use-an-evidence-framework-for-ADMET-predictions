Author-created code uses the repository's existing MIT licence; third-party source-derived materials retain the terms recorded in `LICENSE_STATUS.md` and the source manifests. No Zenodo DOI is assigned or implied.

## Scope and manuscript mapping

This package preserves frozen secondary calculations for the ADMET review and provides the v14 figure source code. It supports traceability of selected source records, not model training, independent validation of the original studies, reconstruction of unresolved original analyses or a new model-performance claim. No new experimental data were generated.

The four checks concern DeepDelta chemical-identity overlap, PPB metric definitions, the seven-drug biliary calculation and Nature supplied-column/finite-pair comparisons. Their source correspondence limits remain unresolved where explicitly stated. The legacy industrial Figure 7 values map to v14 Figure 4(d–f). `draw_figures.py` produces v14 Figures 2, 3 and 5 (delegating the current Figure 5 to `draw_figure5.py`) (schematic label handling, an illustrative error model, and the proposed evidence framework). `build_figure04.py` replots the 20 source values in `figure04_source_data.csv` for v14 Figure 4. The source CSV retains explicitly labelled v13 reference identifiers; DOI identifiers establish provenance across manuscript renumbering. Figure 1 is not regenerated by these scripts.

## Run from this directory

Python 3.10 or newer is required for the standard-library replay. This package was checked with Python 3.12.14. Frozen replay has no third-party dependencies:

```text
python second_verification/replay.py
```

It writes `replay_outputs/results.json` and `replay_outputs/nature_masks.csv`. Scientific values and masks can be compared with `second_verification/expected_outputs/`; the recorded Python version is environment metadata and may differ. A successful script prints `PASS_FROZEN_CALCULATION_REPLAY`.

For plots, install the recorded dependencies into your own environment and run:

```text
python -m pip install -r requirements.txt
python draw_figures.py
python build_figure04.py
python figure07_replay.py
```

The first two scripts write PNG/PDF/SVG to `figure_replay_outputs/`; the legacy industrial plot writes to `figure07_replay_outputs/`. Matplotlib's DejaVu Sans font is used; no private path or system font file is needed. The English legacy plot therefore preserves point values rather than its old Arial-based pixel hash. Typical local execution was measured during preparation; see `REPLAY_CHECK.md`. Do not compare PDF/SVG file hashes as evidence of scientific change because creation metadata can vary.

Optional extraction is a different task. In a separate environment, install `requirements-source-extraction.txt`, obtain the four exact source snapshots named in the source manifest, and run:

```text
python second_verification/extract_inputs.py path/to/originals
```

This package preparation did not rerun source extraction or substitute new remote snapshots. Original workbooks/articles are not included. Source files must match their recorded hashes.

## Known limitations and rights

The supplied Nature rules reproduce a frozen calculation, not the publication's unresolved final masks/column mapping. The second biliary correlation remains an unresolved source-correspondence discrepancy. PPB squared correlation and predictive R-squared are distinct; no rewritten source conclusion is asserted. Raw-string overlap does not quantify predictive leakage impact. Case comparators differ and do not establish a common success rate or incremental AI benefit; PAMPA axes are omitted where source units are absent. No uncertainty or measurements have been invented.
